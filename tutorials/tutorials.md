# Tutorials and Learning Resources

This section contains tutorials, documentation, and learning resources for understanding and evaluating LLM factuality, hallucination, retrieval-augmented generation, and evidence grounding.

---

## 1. DeepEval — RAG Evaluation Guide

- **Type:** Tutorial / Documentation
- **Topic:** RAG evaluation, faithfulness, hallucination
- **Description:** This guide explains how to evaluate Retrieval-Augmented Generation systems using metrics such as answer relevancy and faithfulness.
- **Why Useful:** Faithfulness measures whether generated information is consistent with the retrieved context.
- **Link:** https://deepeval.com/guides/guides-rag-evaluation

---

## 2. DeepEval — Faithfulness Metric

- **Type:** Documentation / Tutorial
- **Topic:** Factuality and RAG faithfulness
- **Description:** Explains how the faithfulness metric evaluates whether claims in an LLM response are supported by the retrieved context.
- **Why Useful:** It provides a practical way to evaluate factual grounding in RAG applications.
- **Link:** https://deepeval.com/docs/metrics-faithfulness

---

## 3. TruLens — RAG Triad

- **Type:** Tutorial / Documentation
- **Topic:** RAG evaluation
- **Description:** Introduces the RAG Triad consisting of context relevance, groundedness, and answer relevance.
- **Why Useful:** These three evaluations help identify problems in retrieval and generation that can lead to hallucinations.
- **Link:** https://www.trulens.org/getting_started/core_concepts/rag_triad/

## 4. TruLens — Ground Truth Evaluations

- **Topic:** Ground-truth evaluation
- **Description:** Demonstrates how to evaluate an LLM application by comparing generated responses against verified responses.
- **Why Useful:** Ground-truth evaluation is useful when evaluating a small set of important questions where correctness is critical.
- **Link:** https://www.trulens.org/getting_started/quickstarts/groundtruth_evals/

## Learning Path

A beginner can use these resources in the following order:

1. Learn the basics of LLM evaluation.
2. Learn what hallucination and factuality mean.
3. Learn Retrieval-Augmented Generation (RAG).
4. Learn how retrieval quality affects factuality.
5. Learn faithfulness and groundedness evaluation.
6. Practice evaluating a small RAG application.
7. Explore scientific claim verification datasets such as SciFact.
8. Study research benchmarks such as FActScore, HaluEval, and TruthfulQA.

---

## Important Evaluation Concepts

### Factuality

Whether information generated by an LLM is factually correct.

### Hallucination

Information generated by an LLM that is unsupported, incorrect, or inconsistent with available evidence.

### Faithfulness

Whether a generated answer is supported by the context or evidence provided to the model.

### Groundedness

Whether the claims in a generated answer are supported by the retrieved information.

### Claim Verification

The process of determining whether a claim is supported or contradicted by available evidence.

### Retrieval-Augmented Generation

A method in which an LLM retrieves external information and uses that information to generate an answer.

**LLM basics → Factuality → Hallucination → Scientific Claim Verification → RAG → Evidence Grounding → Factuality Evaluation → Benchmarking**
